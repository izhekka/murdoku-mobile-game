# AGENTS.md — Murdoku

## What is Murdoku?

Murdoku (working title) is an offline murder-mystery logic puzzle built with
Flutter: place every guest on the mansion map so each row, column and room
holds exactly one guest, follow the clue cards, then accuse the guest who ends
up alone with the victim.

- **Stack:** Flutter, targeting desktop and mobile; runtime dependencies are
  flutter_riverpod, go_router, shared_preferences.
- **Fully offline:** no networking, analytics, ads, tracking, or permissions.
- **No binary art:** item sprites are game-icons.net SVGs built by
  `tool/build_item_icons.sh` (CC BY 3.0 — attribution line is in the Settings
  screen); the launcher icon is generated by `tool/gen_icon.dart`.
- **Procedural cases:** seeded generation at three difficulties, verified to a
  unique solution, plus a daily case derived from the UTC date.
- **Russian/English UI:** all user-facing strings go through AppLocalizations
  (arb files).

## Build, run, test

```bash
flutter pub get                                           # fetch dependencies
flutter run                                               # run on an attached device/emulator
flutter analyze                                           # static analysis — must report 0 issues
flutter test                                              # unit + widget tests — all must pass
flutter test integration_test/smoke_test.dart -d <device> # full-loop smoke test
bash tool/build_item_icons.sh                             # rebuild the item sprites in assets/items/
dart run tool/gen_icon.dart                               # regenerate the launcher icon
dart run tool/preview_items.dart                          # render a labeled preview of the item sprite set
```

## Guardrails (summary of plan §1)

- Work task-by-task, TDD: failing test first, then minimal implementation, then green.
- Gate after every task: `flutter analyze` (0 issues) && `flutter test` (all pass), then commit.
- Runtime dependencies are exactly: flutter_riverpod, go_router, shared_preferences
  (plus Flutter-template defaults). Dev-only extras: image, flutter_launcher_icons (Task 17).
- No code generation / build_runner / freezed. Hand-written toJson/fromJson.
- Fully offline; no networking, analytics, ads, or permissions.
- All user-facing strings go through AppLocalizations (arb files).
- Never edit generated output: `lib/l10n/generated/**`, `**/.dart_tool/**`, `*.g.dart`.
- "Murdoku" is a working title — trademark risk; rename before store submission (Task 17).

## Item sprites (ownership)

- ALL `assets/items/*.png` (15 files: 14 item kinds + victim) are built by
  `tool/build_item_icons.sh` from game-icons.net SVGs (CC BY 3.0 — attribution
  line is in the Settings screen and README). Do NOT hand-draw or replace them
  with other sources without keeping that attribution.
- `tool/preview_items.dart` renders a labeled preview of the whole set.
- To change an item graphic: edit the icon path/color in
  `tool/build_item_icons.sh`, run it, commit the PNG.
